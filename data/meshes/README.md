# Mesh data

Small vascular-tree files are stored in `data/vascular_trees/`.

The larger ventricular-section mesh files are provided as a GitHub release asset named `large_meshes.zip`:

- `teste.xml`: ventricular-section mesh with arterial tree.
- `testeNoTree.xml`: ventricular-section mesh without arterial tree.
- `arvoreCoracao.trelis`: Trelis/CUBIT project file used during geometry preparation.

After downloading the release asset, unzip it in the repository root so that the files appear under `data/meshes/`.
